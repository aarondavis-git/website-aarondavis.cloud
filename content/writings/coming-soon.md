This is a placeholder note showing what a Writings card looks like once
the Markdown pipeline is wired up.

To add a real piece: drop a new `.md` file into `content/writings/`, with
the same frontmatter block (`title`, `summary`, `date`) at the top followed
by the piece itself in plain Markdown — headings, lists, links, and inline
math like $\LaTeX$ all work. A new card and page appear automatically the
next time the site builds; nothing else needs to change.

You can delete this file once the first real piece is in place.
