platform.

## Scope

- Mapped the legacy schema onto the new platform's data model, resolving a
  handful of fields that didn't have a clean one-to-one equivalent.
- Wrote the migration pipeline that moved every record across without
  manual intervention.
- Verified a clean, zero-loss handover with row-level reconciliation before
  the legacy system was decommissioned.
